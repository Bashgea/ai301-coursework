# Rubric: is this a good first issue?

## Checks

| Check | Evidence | Pass condition | Weight |
|---|---|---|---|
| Repo actively maintained | Commit history from default branch (in repo-facts block) | At least one commit in the last 60 days | required |
| Maintainer engaged | Repo-facts: last push date and maintainer response sample | Repo has pushed in last 30 days OR maintainer has responded to at least 1 of the 5 recent issues in the sample | required |
| Issue is scoped for beginner | Issue body description, labels, and scope | Has a clear description of what needs to be done; task scope is bounded (not open-ended); a newcomer could understand the work without deep codebase knowledge | required |
| Not already claimed | Issue comments and "Assignees" field in repo-facts | No existing claim comment from another student; assignees field is empty | required |
| Clear acceptance criteria | Issue body | Contains specific steps to reproduce, acceptance criteria, or expected behavior (e.g., "when X, expect Y") | preferred |

## Verdict rule

Accept if all required checks pass. Preferred checks never change the verdict; they rank accepted issues higher. If any check is unclear or pass condition cannot be determined, treat as fail.
